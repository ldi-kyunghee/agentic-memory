#+title: Retrieval 방법 비교 및 분석
#+startup: shrink inlineimages
* Naive 메모리 vs Mem0 비교
먼저 BM25가 멤제로보다 더 잘 하는 케이스부터 분석해 보고 그 반대인 케이스를 살펴 봅니다. 마지막에, 답이 비슷했어도 llm-as-a-Judge가 다르게 평가하는 샘플도 확인해 봅니다.

모델 분포 등 변수를 없애버리도록, 같은 모델의 결과를 비교해 보고, BM25 경우, Mem0의 세팅을 최대하게 맞추어 봐서 실험해 보았습니다. 같은 모델 유지하면 직관적으로는 =retrieved_memory= 만 달라 부일치한 결과 나타난 원인은 (원칙적으로) 아래와 같다고 생각합니다.
1. Naive memory 혹은 agentic memory (혹은 둘다)로써 뽑게 된 문서는 질문과 관련성이 적거나 질문의 핵심은 아예 포함되지 않기 때문
2. 문서 순서에 따라 'lost-in-the-middle' 발생하는 것
3. 관련 문서를 잘 골랐어도, 노이즈처럼 포함된 별로 관련없는 문서로써 답변을 생각하며, 할루시네이션 발생하기 때문

** BM25 Mem0보다 더 잘 하는 케이스
예시 1
#+begin_src json
  {
      "Question": "What is Martin's friend's name whose Golden Retriever he interacted with on Jan 06, 2026?",
      "Reference": "The name of Martin's friend is not provided.",
      "BM25": "Not provided.",
      "Mem0": "ThomasSusan"
  }
#+end_src

예시 1에서, Mem0가 틀렸으나 BM25 맞는 것으로 답변하는 케이스입니다. Dialogue에서 마틴의 친구 이름이 언급되지 않아 BM25로 retrieval해봐도 못 찾는 거라 맞습니다. Mem0도 retrieved documents에서도 관련 메모리에서 마틴의 친구가 언급되지 않습니다만, 뽑은 context에서:
#+begin_src json
  {
      "context": "Sep 05, 2025, 22:32:20: ThomasSusan is a friend",
  }
#+end_src
관련성 5위로 나타나, 상황과 적절하지 않아도 "connecting the dots"으로 친구 이름은 ThomasSusan이라고 답변하는 모양입니다.
- 즉, 2025년 기준, 마틴은 ThomasSusan이라는 친구가 있다는 걸 알고 있어, 2026년에도 당연히 아직도 친구일거고 dialogue 혹은 관련 context (아래 참고)에서 친구 이름이 없길래 모델은 알고있는 유일한 친구인 ThomasSusan이라고 대충 답변하는 모양입니다.
   #+begin_src json
     {
         "context": "Jan 06, 2026, 17:48:59: Interacted with a friend's Golden Retriever and found its adaptability impressive",
     }
   #+end_src

   심지어, Mem0 경우 reasoning trace 같은 것 없어 본인의 리즈닝인데, 저렇다고 판단하는 이유는 노이지한 답변 생성으로 인해 망하던 실험에서 LLM은 "문서에서 딱히 언급되지 않았다"라고 맞게 검토했어도 답변이 없을리가 없다는 마인드로 드디어 LLM은 "그냥 ㅇㅇ라고 대충 답하자" 하는 버릇이 있는 것으로 확인하였습니다.

그리고, 

** Mem0 Naive보다 더 잘 하는 케이스
BM25, 엠베딩과 하이브리드는 다 inference 관련 질문에 어려워 합니다.
즉, 명확히 언급되지 않고 대신에 속은 의미 혹은 결론을 내려야 하는 질문에 retrieval하기는 어려워 합니다.

** Judge LLM 일관성 문제
비교하다보니, LLM은 =Correct= 과 =Omission= 분리하여 평가하기에 어려워 합니다.

평가 모델: gpt-oss-120b (naive과 agentic 모델 비교 같음)
#+begin_src json
  {
      "Question": "Did Martin Mark work as a nurse at Huaxin Consulting on Sep 06, 2025?",
      "Reference": "No, Martin Mark is a director at Huaxin Consulting.",
      "BM25": "No, he was a director.", # 평가 결과: Correct
      "Mem0": "No, he is a director.", # 평가 결과: Omission
  }
#+end_src

윗 샘플을 보시다시피, 시제를 제외 두 답변은 *똑같았어도* 평가 레이블은 다르게 나타났습니다.
